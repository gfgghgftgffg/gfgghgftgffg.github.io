01 Developer Tool / Multi-Agent Workflows

Task Router

A multi-agent tool for Codex and Pi that lets the main agent delegate work to five subagent roles: coding, search, verify, reasoning, and general. Each role can have multiple model and reasoning-level combinations. The main agent chooses a suitable combination for each subtask based on its complexity, risk, and context size, so routine work and difficult problems can use different models and thinking levels. A separate verify agent checks completed coding work.

  • Codex & Pi
  • Per-task model selection
  • Configurable thinking levels

02 Developer Tool / Agent Environment Setup

Amox Agent Bootstrap

Personal setup instructions for Codex and Pi on Windows, macOS, and Linux. Give the appropriate setup file to your agent to check dependencies, configure tools and skills, and verify the installation. Separate bundles preserve each agent's settings, reuse compatible installations, and leave credentials for local configuration.

  • Codex & Pi
  • Cross-platform setup
  • Reusable configuration

03 Pi Extensions / Tool Context Reduction

Amox Pi Extensions Lean

A personal collection of Pi extensions for web access, task tracking, and subagent workflows. It provides more compact tool descriptions, parameter schemas, and unified interfaces, with detailed help available on demand, so tool definitions take up less context during agent sessions.

  • Compact tool schemas

04 Agent Skill / Meeting Intelligence

Meeting Summary HTML

An agent skill that transforms meeting transcripts, text files, or local audio/video into a grounded, self-contained HTML meeting brief. It transcribes media and produces a structured document with chapters, speaker summaries, viewpoint analysis, decisions, action items, risks, and timestamp references.

  • Agent skill

05 Windows Utility / Local Task Capture

QuickTodoAdder

A Windows hotkey utility that turns selected text from any app into actionable tasks for sleek and todo.txt. A configured local model extracts the task, priority, due date, and due time, then writes a sleek-compatible todo entry directly into the shared task file.

  • Selected text
  • Local model
  • sleek / todo.txt

06 Windows Utility / Game Translation

Dota 2 Translator CLI

A Windows global-hotkey tool for translating Dota 2 team chat with locally hosted models. It captures the current chat input, protects Dota-specific terminology with an editable glossary, sends the text to Ollama or llama.cpp, then pastes and sends the translated message back to the game.

  • Global hotkey
  • Dota glossary
  • Ollama / llama.cpp
